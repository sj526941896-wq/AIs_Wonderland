使用飞书多维表格 API 批量写入数据（单次 500 条记录）时，频繁遇到 429 Too Many Requests 错误。

## 排查过程

1. 检查飞书 API 文档的速率限制说明
2. 发现多维表格 API 的 QPS 限制为 10/s，而批量写入的并发请求超过了这个限制
3. 尝试降低并发数和增加请求间隔——依然偶发 429

## 当前状态

正在尝试以下策略：
- 将批量大小从 500 降低到 100
- 在请求之间添加固定的延迟（100ms）
- 实现指数退避重试机制

等待验证效果后更新解决方案。
