# tmux翻页
- 被 tmux 给折腾疯了，用鼠标翻页，结果只在输入命令的地方疯狂更换上一个命令，但输出框纹丝不动，找了教程，也没有看懂，后来问了 gemini，认真实践了下，算搞懂了

键盘翻页快捷键进入复制模式后，使用以下按键进行翻页：￼￼
- 整页滚动： 按 Page Up 
- 向上翻页，Page Down 
- 向下翻页（macOS 键盘使用 Fn + ↑ / Fn + ↓）。
- 半页滚动： 按 Ctrl + u 向上翻半页，Ctrl + d 向下翻半页。
- 逐行滚动： 按键盘 ↑ / ↓ 键逐行查看。
- 退出翻页： 按 q 键退出复制模式，返回终端正常输入状态。￼￼

- 开启鼠标滚轮翻页（推荐）如果你习惯直接使用鼠标滚轮，可以在终端临时开启鼠标支持：￼
1. 按下 Ctrl + b 释放后，输入 : 进入命令模式。

2. 输入 set -g mouse on 并按回车。
3. 之后即可直接通过鼠标滚轮上下翻屏。

玩 tmux 其实不需要背下所有快捷键，日常使用中，**超过 90% 的场景只会用到以下这 6 个核心操作**。

记住那个核心铁律：所有快捷键都要先按 **`Ctrl + b`**（松开），再按后面的字母。

### 👑 频率最高：Top 6 必会快捷键

#### 1. 挂起与恢复（tmux 的灵魂）

- **`Ctrl + b` ➡️ `d` (Detach)**
    
    - **作用：** 把当前会话安全丢到后台，你可以放心关闭终端或断开 SSH。
        
    - **配套命令：** 下次进来时，在普通终端输入 `tmux a`（Attach），瞬间回到现场。
        

#### 2. 临时放大/缩小分屏

- **`Ctrl + b` ➡️ `z` (Zoom)**
    
    - **作用：** 把当前正在操作的那个小分屏**瞬间放大到全屏**。再按一次 `Ctrl + b` + `z` 恢复分屏。
        
    - **场景：** 分屏太多时，突然要看大段的日志或写长代码，这个用得极多。
        

#### 3. 最常用的左右分屏

- **`Ctrl + b` ➡️ `%`**
    
    - **作用：** 把当前屏幕**左右平分**。
        
    - **场景：** 左边开个文本编辑器（如 Vim/Nano），右边准备运行程序。
        

#### 4. 在分屏之间跳跃

- **`Ctrl + b` ➡️ `方向键` (↑ ↓ ← →)**
    
    - **作用：** 你的光标在哪个分屏，你就正在操作哪个分屏。用方向键直接切换。
        

#### 5. 翻页/滚动查看历史日志（核心痛点）

- **`Ctrl + b` ➡️ `[`**
    
    - **作用：** 进入“复制/滚动模式”。
        
    - **怎么用：** 很多人发现进了 tmux 鼠标滑轮没法翻页看上面的日志。按这个组合键后，你就可以用键盘的 **`PageUp / PageDown`** 或者 **`方向键`** 往上翻页了。
        
    - **退出：** 按 **`q`** 键退出，回到正常的终端打字状态。
        

#### 6. 关闭当前分屏

- **`Ctrl + b` ➡️ `x`**
    
    - **作用：** 强行关闭当前光标所在的那个小分屏（会弹出一个 `y/n` 的确认提示）。
        
    - _注：你也可以直接在分屏里打 `exit` 回车，效果一样。_
        

> 💡 **给新手的建议：**
> 
> 刚开始用，重点记住 **`%`（左右分屏）**、**`z`（最大化）** 和 **`d`（丢后台）**。光是这三个，就能解决你 80% 的多任务和防断线需求了！
