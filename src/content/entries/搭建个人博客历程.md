既然学习AI，输入很重要，输出也非常重要。
早些年尝试过用 wordpress等，但最终用的都不是很理想，搭建起来非常麻烦。
> 大人，时代变了

想做就做，打开我的 deepseek-tui，告诉他我想做个博客系统，几分钟就做好了。很是简洁，但发布上有点问题；后来有建立了一个后台来写文章。想着想着又搞复杂了。
- 这是ai时代最容易犯的毛病，没有想清楚就动手了，结果改来改去又费了不少时间
吃饭的时候，突然想到，现在是否有现成的博客系统，适合写东西有轻量的平台，可以直接部署在 github 上的那种，于是 astro 出现在我的视野里。剩下的事情就很简单了，告诉 deepseek用 Astro 去做就好了。
现在，我只要写个 markdown 就可以了。
优雅～
原来那些遥不可及的事，却如此轻易的触及。
> 大人，时代变了！
